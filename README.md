# 노노그램

행과 열 힌트를 읽고 그림을 완성하는 한국어 10×10 퍼즐 게임입니다. 원본 source에 포함된 로켓·하트·고양이 3개 퍼즐을 유지합니다.

## 실행

Node.js 22.12 이상과 npm이 필요합니다. CI는 Node.js 24를 사용합니다.

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run dev
```

빌드 결과는 `dist/`에 생성됩니다. `npm run preview`로 확인하거나 정적 hosting에 `dist/`를 배포할 수 있습니다. 환경 변수나 서버 API는 필요하지 않습니다.

## 플레이

- `채우기`, `X 표시`, `지우기`를 선택하고 칸을 누릅니다. 같은 표시를 다시 누르면 지웁니다.
- 마우스 오른쪽 클릭으로 X 표시를 입력할 수 있습니다.
- 각 칸은 행·열 위치와 현재 상태인 `빈칸`, `채움`, `X 표시`를 접근성 이름으로 제공합니다. 정답 위치는 이름에 포함하지 않습니다.
- 행·열 숫자는 연속으로 채울 칸의 길이입니다. 숫자 사이에는 빈 칸이 하나 이상 필요합니다.
- 정답 칸을 모두 채우고 잘못 채운 칸이 없으면 해결됩니다. 빈 칸에 X 표시를 모두 넣을 필요는 없습니다.
- 완성도는 맞게 채운 칸을 정답 칸과 잘못 채운 칸의 합으로 나눈 값입니다. 오답 칸이 남아 있으면 100%가 되지 않습니다.
- `다시 시작`과 퍼즐 변경은 보드·시간을 초기화합니다. 새로고침하면 진행 상태가 사라집니다.

퍼즐은 실제 제공 콘텐츠이며 사용자 기록이나 QA fixture가 아닙니다. 계정·서버 저장·기기 간 동기화 기능은 없습니다.

## 검증

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm audit --audit-level=high
```

자동 회귀는 3개 퍼즐의 clue·완료 판정·진행 계산과 실제 칸 button의 상태별 접근성 이름을 확인합니다. 마킹 도구, 퍼즐 전환과 반응형 hint 정렬은 실제 브라우저 QA 범위입니다.
